================================================================================
PERGUNTAS & RESPOSTAS RÁPIDAS
================================================================================

P: Por quanto tempo Loavable leva para deployer?
R: 30-60 segundos após você fazer git push

P: Minha senha hardcoded é problema?
R: Para desenvolvimento não. Para produção, use variáveis de ambiente.

P: Posso editar no Loavable direto?
R: Sim, mas não salva no Git. Edite localmente e faça push.

P: Como voltar se algo quebrou?
R: git revert <commit-hash> e push

P: Pode ter múltiplas pessoas desenvolvendo?
R: Sim! Cada pessoa faz clone, cria branch, e faz PR.

P: Como atualizar documentação?
R: Edite NEXED_ECT_DOCUMENTACAO.txt, commit e push junto.

P: Preciso de servidor? Banco de dados?
R: Para MVP não. HTML puro + localStorage funciona. Depois integre Supabase.
