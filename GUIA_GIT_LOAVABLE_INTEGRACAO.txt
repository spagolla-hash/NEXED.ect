PASSO 2: CONECTAR GIT AO LOAVABLE
================================================================================

2.1 Acessar Loavable
─────────────────────

1. Vá a https://loavable.ai
2. Faça login com sua conta
3. Clique em "New Project" ou "+ Create"

2.2 Conectar ao Git
────────────────────

1. Na tela de criação, escolha a opção:
   - "Import from Git" OU
   - "Connect Repository"

2. Será pedido para:
   - Autorizar Loavable no GitHub/GitLab
   - Selecionar seu repositório "nexed-ect"
   - Escolher branch (main/master)

3. Loavable automaticamente:
   - Clona o repositório
   - Detecta package.json
   - Instala dependências
   - Cria preview da aplicação

2.3 Configurar Loavable
────────────────────────

1. Após importar, Loavable oferece:
   - Preview da aplicação
   - Editor de código (se quiser editar)
   - Environment variables
   - Deploy settings

2. Configure:
   - Ambiente: Development
   - Linguagem: HTML/CSS/JavaScript
   - Build command: (deixe vazio, é arquivo estático)

2.4 Testar Preview
────────────────────

1. Loavable fornece URL de preview
2. Clique em "Open Preview"
3. Verifique:
   - ✅ Página carrega
   - ✅ Login funciona (auto-login)
   - ✅ Logo aparece
   - ✅ Todos os menus aparecem

PASSO 5: CONFIGURAÇÕES ESPECÍFICAS DO LOAVABLE
================================================================================

5.1 Variáveis de Ambiente (Environment Variables)
───────────────────────────────────────────────────

Se seu HTML precisar de variáveis:

1. Em Loavable, vá a:
   Settings → Environment Variables

2. Adicione:

VITE_APP_NAME=NEXED ECT
VITE_APP_VERSION=1.0.0
VITE_API_URL=https://api.sua-url.com (opcional)

3. Para acessar no HTML:
   // Será injetado como window.env.VITE_APP_NAME
   const appName = window.env?.VITE_APP_NAME || 'NEXED.ect';

5.2 Configurar Domínio Customizado
─────────────────────────────────────

1. Em Loavable, vá a:
   Settings → Domains

2. Clique em "+ Add Domain"

3. Digite seu domínio (ex: nexed-ect.seu-dominio.com)

4. Loavable fornece instruções DNS:
   - Crie CNAME apontando para Loavable

5. Aguarde validação (5-30 min)

6. Seu app estará em: https://nexed-ect.seu-dominio.com

5.3 Configurar Webhooks (Automação)
─────────────────────────────────────

1. Em Loavable, vá a:
   Settings → Webhooks

2. Clique em "+ New Webhook"

3. Configure:
   - URL: https://seu-servidor.com/webhook
   - Eventos: 'deployment.completed', 'push.received'
   - Método: POST

4. Seu servidor receberá notificações automáticas

5.4 Analytics & Logs
──────────────────────

1. Loavable oferece:
   - Logs em tempo real
   - Analytics de uso
   - Erros e exceções

2. Acesse em:
   Dashboard → Logs
   Dashboard → Analytics

================================================================================
PASSO 7: TROUBLESHOOTING & FAQ
================================================================================

P: Fiz push, mas Loavable não atualizou
R: 
1. Loavable pode levar 30-60 segundos
2. Atualize a página preview (F5)
3. Verifique Logs em Loavable (Dashboard → Logs)
4. Se errr, veja mensagem de erro
5. Rollback: git revert último commit, push novamente

P: Como testar HTML sem Loavable?
R:
1. npm install -g http-server
2. http-server -p 8000
3. Abra http://localhost:8000/lwp73-setproject.html

P: Preciso editar em produção urgente
R:
1. Não recomendado! Mas se necessário:
2. Em Loavable, vá a: Code Editor
3. Edite diretamente no editor web (não é persistente no git)
4. Depois faça mudança localmente, commit e push

P: Como voltar para uma versão anterior?
R:
1. No Git: git log (veja commits)
2. git checkout <hash-do-commit-anterior>
3. git push origin main --force (cuidado!)
4. Loavable automaticamente volta versão

P: Como colaborar em time?
R:
1. Cada dev faz clone do repo
2. Cria branch: git checkout -b feature/nova-funcao
3. Edita e testa
4. Faz PR (Pull Request) no GitHub
5. Code review
6. Merge na main
7. Loavable deploy automático

P: Posso acessar BD/Storage do Loavable?
R:
1. Seu HTML usa localStorage do browser
2. Dados são locais do usuário
3. Se quer sincronizar entre devices:
   - Integre com Supabase, Firebase, ou seu API
   - Veja seção "Integração com Supabase" da docs
